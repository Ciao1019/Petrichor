# 站内助手跨会话记忆与可进化流程

## 用户故事

- 作为站点唯一的超级管理员，我希望助手跨对话记住我的偏好和约定，而不是每次新开线程都从零解释「我平时怎么写、什么别碰」。
- 作为经常在对话里办复杂事的人，我希望它把已经跑通的做法沉淀成可复用流程，下次同类任务少走弯路；新建或大改流程时先给我审一眼，而不是悄悄改掉我依赖的步骤。
- 作为愿意主动改进助手的人，我希望自己点一下就能看到基于过去表现的改进提案，由我决定合不合入，而不是系统在后台自动改生产行为。
- 作为实际几乎只有我一个人用站的人，我希望这套记忆和流程只为我服务，而不要把力气花在多用户偏好冲突、同事共享技能库上。

## 为什么需要

站内对话已经能查事、办事，但每次会话仍像在和一个「健忘的新人」合作：偏好要重复交代，好不容易摸清的做法留不下来，也没有正经的方式把「哪里老翻车」变成可审阅的改进。曾经做过记忆相关能力，又因入口散乱、价值不清被拿掉；现在主入口已经收成一个对话，缺的是真正让助手随使用变熟的那一层——不是再做一个记忆页。

## 怎么解决

对超级管理员，助手长期带着一份精炼的个人画像与约定进每一场对话，并在使用中自行维护这份短记忆。需要回想「以前某次具体怎么做的」时，能按关键词或语义去翻历史对话，而不是把所有旧聊天一股脑塞进窗口。复杂且跑通的做法可以沉淀成可复用流程，目录常在、正文按需展开；新建和大改要人点头。另外提供「我来触发」的改进通道：基于过往表现给出提案，合不合入由人决定。普通登录用户不走这套读写。

## 边界

- 只服务站点超级管理员（个人操作员模型）；不为普通用户做跨会话记忆，也不做多用户之间的偏好/流程冲突合并。
- 不管同事之间共享同一套流程库、也不按知识库/空间隔离另一套记忆——那是以后的事。
- 不通过改模型权重让助手「变聪明」；进化指的是可审阅的流程与约定改进提案，且必须人手触发、人手合入，禁止静默自动改生产。
- 不恢复已下线的独立「记忆」主入口页；管理与审批挂在对话或设置旁路即可。
- 不替代对话主入口本身（查资料、改内容、危险确认等仍由站内助手主能力负责）；本能力解决的是「记得住、可复用、可改进」。
- 前提：超级管理员已登录，且对话所需模型已配置好。
