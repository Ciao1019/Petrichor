# 公开文档问答 Pi 更新与部署

2026-09-23 已发布至 <https://wl.do>，发布标识 `publicqa-20260923-v1`。

## 功能范围

- `/ask` 的文档、Wiki 问答统一使用 Pi Agent Core，模型供应商适配继续使用 Go 模型网关。
- 只提供公开文档/Wiki 的目录、检索、阅读和来源引用；不加载私人助手的浏览器、MCP、技能、沙箱、写入或委派工具。
- 检索复用公开全文与语义召回及 RRF 融合；语义不可用回退全文，未建索引文章保留原文匹配。
- 每次工具执行刷新公开文章范围；Wiki 与目录节点需所有来源及构建记录可公开，同名 Wiki 按知识库 ID 读取。
- 引用卡只接受本轮工具实际返回且仍有效的公开链接；标题和摘要从工具证据恢复。
- 修复旧 Wiki 概览扫描列不匹配，补充分页和真实来源链接；长文支持字符分页。
- 客户端历史只接受普通对话文本，忽略 system/developer/tool 角色和伪造工具结果。请求体、历史、输出、模型轮次、工具次数与执行时间均有上限。
