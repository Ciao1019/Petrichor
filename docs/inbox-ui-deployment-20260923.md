# 随笔「随手写 / 网页采集」界面重构部署记录

2026-09-23 已部署至 <https://wl.do>，发布标识 `inbox-20260923-v1`。

## 发布内容

- 随笔页改为单栏布局，移除右侧概览栏；计数并入状态筛选，标签超过 12 个时折叠，筛选后显示结果数与清除入口。
- 「随手写」与「网页采集」合并为一张卡片，卡片头部使用可键盘切换的标签页，两侧草稿与采集状态保持挂载。
- 随手写的紧凑编辑器去掉顶部整条工具栏，改为底部轻量操作条（待办、列表、引用、图片），标签、字数与「记下来 ⌘↵」并入同一行；文字格式交给选区浮动工具栏与 `/` 命令。
- 网页采集去掉标题说明，改为可自动增高的链接输入与单行操作；采集中显示「排队 → 采集网页 → AI 整理」进度，失败状态紧凑展示；结果页头部合并返回、来源与视图切换，想法与标签直接展开。
- 随笔卡片使用新增的 Phosphor `push-pin` 图标表示置顶，悬停或键盘聚焦时显示编辑、置顶、归档快捷操作；标签、网页来源与归档信息合并为一行。
- `PlateMarkdownEditor` 的 `compact` 模式新增 `compactActions`，仅随笔相关组件使用。
