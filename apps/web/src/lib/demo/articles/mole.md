## 什么是 Mole？

**Mole**（小鼹鼠）是一款专为 macOS 设计的**开源、免费**的命令行清理工具。它就像一只勤劳的小鼹鼠，能够深入挖掘你的 Mac 系统，清理掉各种垃圾文件、缓存和残留文件。


### 主要特点：

* ✅ **完全免费开源**：无广告、无付费陷阱
* ✅ **功能强大**：相当于 CleanMyMac + AppCleaner + DaisyDisk + iStat 等多款付费软件的组合
* ✅ **轻量安全**：体积小巧，无后台驻留进程
* ✅ **操作简单**：几个简单命令就能完成清理
* ✅ **安全可控**：支持预览模式和白名单功能

***

## 为什么要用 Mole？

### 适用场景：

1. **磁盘空间不足**：Mac 提示存储空间已满
2. **系统运行缓慢**：电脑卡顿、发热严重
3. **卸载软件不干净**：删除应用后仍有残留文件
4. **开发者清理**：Node. Js、Xcode 等开发工具产生大量缓存
5. **日常维护**：定期清理系统，保持 Mac 健康运行

### Mole 的五大核心功能：

| 功能   | 命令             | 说明                      |
| ---- | -------------- | ----------------------- |
| 深度清理 | `mo clean`     | 清理系统缓存、日志、浏览器缓存、开发工具垃圾等 |
| 智能卸载 | `mo uninstall` | 彻底卸载应用及其所有关联文件          |
| 磁盘分析 | `mo analyze`   | 可视化显示磁盘空间占用情况           |
| 系统优化 | `mo optimize`  | 一键优化系统，重建索引、刷新缓存等       |
| 系统监控 | `mo status`    | 实时查看 CPU、内存、磁盘、网络等运行状态  |

## 准备工作

### 1. 什么是"终端"？

**终端（Terminal）**&#x662F; Mac 内置的一个应用程序，它允许你通过输入文字命令来控制电脑。别被它的黑色界面吓到，其实用起来很简单！

### 2. 如何打开终端？

有两种方法：

**方法一：通过 Spotlight 搜索**

1. 按下键盘上的 `Command（⌘）+ 空格键`
2. 输入"终端"或"Terminal"
3. 按回车键打开

**方法二：通过应用程序文件夹**

1. 打开"访达（Finder）"
2. 点击菜单栏的"前往" → "实用工具"
3. 双击打开"终端"

### 3. 终端基本操作

* **输入命令**：在终端窗口中输入命令后，按 `回车键（Enter）` 执行
* **复制粘贴**：&#x20;
  * 复制：`Command（⌘）+ C`
  * 粘贴：`Command（⌘）+ V`
* **清屏**：`Command（⌘）+ K` 清除终端显示内容
* **查看历史命令**：按 `↑`（上箭头）或 `↓`（下箭头）键

## 安装 Mole

### 方法一：使用 Homebrew 安装（推荐）

**什么是 Homebrew？**
&#x20;Homebrew 是 Mac 上最流行的软件包管理工具，可以方便地安装和管理命令行工具。

#### 步骤 1：检查是否已安装 Homebrew

打开终端，输入以下命令：

```
brew --version
```

* 如果显示版本号（如 `Homebrew 4.x.x`），说明已经安装，可以跳到步骤 2
* 如果提示"command not found"，说明未安装，请先安装 Homebrew

#### 步骤 1.1：安装 Homebrew（如果还没有）

在终端中复制粘贴以下命令，然后按回车：

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

**注意事项：**

* 安装过程中会提示输入你的 Mac 登录密码（输入时不会显示任何字符，这是正常的）
* 耐心等待，安装可能需要几分钟
* 如果下载速度很慢，可以尝试国内镜像安装方法（搜索"Homebrew 国内镜像安装"）

#### 步骤 2：使用 Homebrew 安装 Mole

安装完 Homebrew 后，依次执行以下命令：

```
brew install mole
```

安装完成后，输入以下命令验证是否安装成功：

```
mo --version
```

如果显示版本号，说明安装成功！

***

### 方法二：使用官方脚本安装

如果你不想使用 Homebrew，可以直接运行官方安装脚本：

```
curl -fsSL https://raw.githubusercontent.com/tw93/mole/main/install.sh | bash
```

**说明：**

* 这个命令会自动下载并安装 Mole
* 同样需要输入密码
* 安装完成后，输入 `mo --version` 验证

## 核心功能详解

安装完成后，你可以在终端输入 `mo` 命令来使用 Mole。以下是各个功能的详细说明。

### 1. 🧹 深度清理（mo clean）

这是 Mole 最强大的功能，可以清理各种垃圾文件。

#### 基本使用：

```
mo clean
```

#### 清理内容包括：

* **系统缓存**：用户应用缓存、系统日志、临时文件
* **浏览器缓存**：Chrome、Safari、Firefox、Edge 等浏览器缓存
* **开发工具垃圾**：&#x20;
  * Xcode 派生数据（DerivedData）
  * Node. Js/npm 缓存
  * Python 虚拟环境
  * Rust、Go 等语言的构建缓存
* **其他应用缓存**：Spotify、Dropbox、Slack 等应用的缓存文件
* **废纸篓**：清空废纸篓
* **. DS\_Store 文件**：Mac 系统产生的隐藏文件

#### 预览模式（推荐首次使用）：

在实际删除前先看看会清理哪些内容：

```
mo clean --dry-run
```

**重要提示**：首次使用建议先运行预览模式，检查一下要删除的内容，确保没有重要文件。

#### 实际效果：

运行后，终端会显示类似以下内容：

```

### 2. 📦 智能卸载（mo uninstall）

不仅删除应用本身，还能清理所有关联的配置文件、缓存、启动项等。

#### 使用方法：

```
mo uninstall
```

#### 操作流程：

1. 运行命令后，会列出你安装的所有应用
2. 使用 `↑` `↓` 方向键选择要卸载的应用
3. 按 `空格键` 勾选（会显示 ☑）
4. 选择完成后按 `回车键` 确认
5. Mole 会自动查找并列出相关的残留文件
6. 确认后彻底删除

#### 卸载范围：

* 应用程序本身（/Applications/）
* 支持文件和缓存（\~/Library/Application Support/、\~/Library/Caches/）
* 偏好设置（\~/Library/Preferences/）
* 日志文件（\~/Library/Logs/）
* 启动代理（LaunchAgents、LaunchDaemons）
* 浏览器扩展和插件
* 系统级文件（需要 sudo 权限）

## 进阶使用技巧

### 1. 白名单配置

防止 Mole 误删重要文件，可以将特定路径加入白名单。

#### 查看/设置白名单：

```
mo clean --whitelist
```

或者

```
mo optimize --whitelist
```

#### 手动编辑白名单：

白名单配置文件位于：`~/.config/mole/whitelist`

使用文本编辑器打开：

```
open -e ~/.config/mole/whitelist
```

在文件中添加你不希望被清理的路径，每行一个路径，例如：

```
/Users/你的用户名/Library/Caches/com.adobe.CreativeCloud
/Users/你的用户名/Library/Application Support/某重要软件
```

保存后，Mole 将不会清理这些路径下的文件。

***

### 2. Touch ID 授权

让 Mole 在执行需要管理员权限的操作时，使用指纹而不是输入密码。

#### 配置方法：

```
mo touchid
```

运行后，按照提示输入一次密码，之后就可以使用 Touch ID 了。

#### 效果：

以后执行需要 `sudo` 权限的命令时，会弹出 Touch ID 认证窗口，轻触指纹即可授权。

***

### 3. 更新 Mole

Mole 会不断更新以修复 bug 和添加新功能。

#### 更新命令：

如果使用 Homebrew 安装：

```
brew upgrade mole
```

如果使用脚本安装：

```
mo update
```

***

### 4. 查看帮助

查看所有可用命令和选项：

```
mo --help
```

查看特定命令的帮助：

```

mo uninstall --help

### 5. Shell 自动补全

启用 Tab 键自动补全 Mole 命令：

```

配置后，输入 `mo` 再按 `Tab` 键，会自动提示可用的命令。

## 安全注意事项

### ⚠️ 重要提醒：

1. **首次使用前备份**：
   * 虽然 Mole 经过严格测试，但建议先使用 Time Machine 备份重要数据
   * 或者至少备份你认为重要的文件
2. **使用预览模式**：
   * 首次使用 `mo clean` 时，先运行 `mo clean --dry-run` 查看会删除什么
   * 确认没有重要文件后再执行真正的清理
3. **开发者注意**：
   * `mo clean` 会清理 Xcode 的 DerivedData、Node. Js 的缓存等
   * 清理后首次编译可能会变慢（需要重新生成缓存）
   * 如果正在进行重要项目，建议先不要清理开发工具缓存
4. **关键缓存保护**：
   * 使用白名单功能保护重要的缓存文件
   * 例如：某些设计软件的素材缓存、机器学习模型缓存等
5. **系统稳定性**：
   * 如果 Mac 对你非常重要（如工作设备），建议等 Mole 更成熟再使用
   * 或者只使用预览模式和分析功能

## 常见问题解答

### Q 1: Mole 安全吗？会不会删除系统文件？

**A:** Mole 是开源项目，代码公开透明。它只清理缓存、日志、临时文件等，不会删除系统核心文件。但建议首次使用时先用预览模式查看。

***

### Q 2: 清理后软件还能正常使用吗？

**A:** 可以。Mole 只删除缓存和临时文件，不会影响软件功能。但某些软件可能需要重新生成缓存，首次启动会稍慢。

***

### Q 3: 为什么清理后可用空间没增加那么多？

**A:** macOS 有时不会立即更新可用空间显示。重启 Mac 或等待几分钟后，空间会正确显示。

***

### Q 4: 我不小心删除了重要文件怎么办？

**A:**&#x20;

1. 立即停止操作
2. 如果有 Time Machine 备份，可以恢复
3. 尝试使用数据恢复软件（如 Disk Drill）
4. 下次使用前记得先用预览模式和白名单功能

***

### Q 5: Homebrew 安装失败怎么办？

**A:**&#x20;

1. 检查网络连接
2. 尝试使用国内镜像源安装 Homebrew
3. 或者直接使用 Mole 的官方脚本安装

***

### Q 6: 终端提示"command not found: mo"怎么办？

**A:**&#x20;

1. 确认 Mole 是否安装成功
2. 重启终端窗口
3. 如果使用 Homebrew 安装，检查 PATH 环境变量
4. 重新安装 Mole

***

### Q 7: 可以定期自动运行清理吗？

**A:** 可以通过 macOS 的 `launchd` 或 `cron` 设置定时任务，但不建议自动运行。最好手动运行，确保不会误删重要文件。

***

### Q 8: Mole 会上传我的数据吗？

**A:** 不会。Mole 是完全本地运行的工具，不会连接任何服务器，不会收集或上传任何数据。

***

## 卸载 Mole

### 方法一：使用 Mole 自带的卸载命令

```
mo remove
```

### 方法二：使用 Homebrew 卸载（如果用 Homebrew 安装）

brew uninstall mole
```

### 方法三：手动删除

sudo rm -rf /usr/local/bin/mo
